# 📚 Daily Study Timetable & Routine

A clean, responsive, notebook-style daily study timetable designed for intense study sessions paired with a healthy lifestyle routine.

## ✨ Features

- **Notebook Aesthetic**: Ruled notebook lines, spiral holes, handwriting fonts ([Caveat](https://fonts.google.com/specimen/Caveat) and [Patrick Hand](https://fonts.google.com/specimen/Patrick+Hand)), and margin styling.
- **Healthy Daily Routine**: Built-in schedules for morning hydration, workouts, nutritious meals, power naps, and sleep wind-down.
- **Intense Study Blocks**: Multiple 30-minute high-focus study slots with fillable dotted lines for specific subjects/topics.
- **Live Navigation & Indicator**:
  - Live ticking digital clock with status indicator.
  - Active time-slot detection (`▶ NOW` badge and glowing highlight).
  - Daily progress bar (5:00 AM – 9:45 PM) showing elapsed day percentage.
  - Auto-scrolling to the current time slot on load.
- **Task Tracking**: Clickable checkmarks with completion counter and progress bar.
- **Laser-Printer Ready (A4)**: Specially formatted `@media print` CSS strips backgrounds to crisp white, outlines pills, and sizes content to fit exactly on a single A4 page.

## 🚀 Quick Start

Simply open `study_timetable.html` in any modern web browser:

```bash
open study_timetable.html
```

## 🖨️ Printing Instructions

1. Click the **🖨️ Print (A4)** button at the bottom of the page (or press `Cmd + P` / `Ctrl + P`).
2. Set Paper Size to **A4**.
3. Scale: **Fit to printable area** or **100%**.
4. Optional: Disable **Background graphics** for completely white, laser-friendly ink-saving prints.
