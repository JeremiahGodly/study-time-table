## ✨ Features

### 🗒️ Notebook Look & Feel
- Handwriting fonts — [Caveat](https://fonts.google.com/specimen/Caveat) & [Patrick Hand](https://fonts.google.com/specimen/Patrick+Hand)
- Ruled lined background, red margin line, and spiral binding holes
- Color-coded section labels: Health 🔴 · Study 🔵 · Meals 🟠 · Breaks 🟢 · Sleep 🟣

### 🕐 Live Time Indicators
| Indicator | Description |
|---|---|
| **Live Clock** | Fixed badge (top-right) showing current time with a pulsing green dot |
| **▶ NOW marker** | Blue pill label on the currently active time slot |
| **Row highlight** | Soft blue glow on the current session so you never lose your place |
| **Day Progress Bar** | Tracks how far through your 5:00 AM–9:45 PM day you are — with a 🕐 cursor |
| **Auto-scroll** | Page scrolls automatically to the current slot when opened |

### 📋 Task Management
- ✅ Clickable checkboxes with green tick animation
- ~~Strikethrough~~ on completed write-in tasks
- Task completion counter + progress bar

### 📝 Write-in Study Slots
- **16 fillable 30-minute intense study sessions** across 4 study blocks
- Dotted underline input fields — type your subject/topic before each session
- Organized into: Morning · Afternoon · Evening · Night Revision

### 🌿 Built-in Healthy Routine
| Time | Activity |
|---|---|
| 5:00 AM | ☀️ Wake up & stretch |
| 5:30 AM | 🏃 Exercise / Yoga / Walk |
| 6:15 AM | 🥣 Breakfast |
| 10:20 AM | 🍛 Lunch + 😴 Power nap |
| 2:40 PM | 🍎 Healthy snack |
| 6:00 PM | 🏋️ Evening exercise |
| 7:10 PM | 🍽️ Dinner |
| 9:45 PM | 🌙 Lights off — 7.5 hrs sleep |

### 🖨️ Laser-Printer Ready (A4)
- All color fills stripped to **white** at print time
- Colored section pills replaced with outlined white boxes
- Compact two-column layout fitted to a **single A4 sheet**
- Live indicators (clock, NOW badge) hidden during print

```bash
open "study time table/study_timetable.html"
```

Or just **download the ZIP** and double-click `study_timetable.html`.

---

## 🖨️ Printing to A4

1. Open `study_timetable.html` in your browser
2. Click the **🖨️ Print (A4)** button at the bottom
3. In the print dialog:
   - Paper size → **A4**
   - Scale → **Fit to page** or **100%**
   - Background graphics → **OFF** *(for cleanest laser print)*
